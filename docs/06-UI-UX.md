# Screens, accessibility and UX contracts

Portfolio: list/filter commitments, owner, deadlines, state, evidence gaps and risk; no fake counters. Detail: exact promise wording with JSM source; five-stage evidence timeline; requirement checklist; engineering Done / promise Unverified side-by-side. Reviewer: approve extraction, attach signed-off proof, acknowledge, view diff and audit. Admin: policy editor with role check. Empty/error/access denied states essential.

Use Atlassian Design System tokens, accessible form labels, keyboard navigation, focus order and readable contrast. ADS MCP via official Forge AI plugin can provide current components. UI should be resilient to latency with loading skeletons, not hide backend errors; show source link + timestamp. Don't use color as only evidence marker. Use a 1280x720 video-friendly layout and real browser interaction.
